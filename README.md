# Research Library

Public, evidence-backed thematic research published at <https://rsalek.github.io/research/>.

## Structure

```text
research/
├── index.html                         # Research library and report summaries
├── el-nino-commodities-2026.html     # Canonical report with visible version ledger
├── energy-landscape-analysis-2026.html # Individual research report
├── optimizing-ai-systems-2026.html   # Individual research report
└── README.md
```

Each report is a standalone HTML file linked from `index.html`. Its library card should include:

- category and publication date;
- data cut-off;
- a concise decision-oriented summary;
- an `Open report` link and GitHub source link.
